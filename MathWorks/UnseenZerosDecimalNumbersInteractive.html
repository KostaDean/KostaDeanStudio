Unseen Zeros of Decimal Numbers

Learn why decimal numbers can have zeros that are not written, but are still useful in calculations.

Decimal place value

A decimal number tells how many ones, tenths, hundredths, thousandths, and so on a number has.

358.24 = 3 hundreds + 5 tens + 8 ones + 2 tenths + 4 hundredths

The digit 0 can sometimes be unseen. We may not write it, but we may need it when multiplying or dividing by special numbers.

Zeros to the right of a decimal

Zeros at the end of a decimal do not change the value of the number.

358.24 = 358.240 = 358.2400

These all name the same number. The extra zeros are “unseen” unless we need them.

Multiplying by special numbers

When we multiply a decimal by a special number, we move the decimal point to the right as many places as the number of zeros in the special number.

358.24 × 1000 = 358240

Here, 1000 has three zeros, so the decimal point moves 3 places right.

Dividing by special numbers

When we divide a decimal by a special number, we move the decimal point to the left as many places as the number of zeros in the special number.

358.24 ÷ 10000 = 0.035824

Sometimes unseen zeros must be inserted before the number so the decimal point can move far enough left.

The rule



Rule: When multiplying by a special number, move the decimal point right as many places as the number of zeros. When dividing by a special number, move the decimal point left as many places as the number of zeros.
