Arithmetic Expressions

A quantity can be written with numbers and symbols of operations to be calculated.

Order of operations

Grouping symbols like ( ), [ ], and { } indicate the order of operations.

Positive numbers do not need parentheses, but negative numbers must use ( ) to avoid confusing the order of calculations.

Notes:

1) Do the innermost ( ) first, and work outward.

2) When not specified, do multiplication and division first before addition and subtraction.

3) The multiplication sign × is often not written. Quantities can be written side by side, or with a small dot between them.

Example with nested grouping

2[5(−3) + (10 − 8)]
= 2[−15 + 2]
= 2[−13]
= −26

The innermost parts are calculated first: 5(−3) and (10−8).

Examples

(−2) × (7 + 3) = (−2)(7 + 3) = (−2)(10) = −20
(−2)7 + 3 = (−14) + 3 = −11
−82 + 4 = −4 + 4 = 0
(−8) + 42 = −42 = −2

Notice how changing the grouping changes the value.
