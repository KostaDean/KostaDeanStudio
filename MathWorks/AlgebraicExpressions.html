Algebraic Expressions

We can use letters to stand for numbers. These letters are called variables.

Letters can stand for numbers

3 + 7 can be written as a + b, where a = 3 and b = 7.
2(−4) + 67 can be written as ab + cd
where
a = 2
b = −4
c = 6
d = 7

These are examples of algebraic expressions. They describe quantities without saying ahead of time what each number must be.

Form and value

Every quantity has a form and a value. The form shows how to calculate. The value is the numerical answer after the calculation.

ab + c

has the form “multiply a and b, then add c.”

When not specified, multiplication and division are done first before addition and subtraction.

If we want to add first, we write this as a(b + c).

The multiplication sign × is often omitted.

If a = 3, b = 2, and c = 7, then:
(3)(2) + 7 = 6 + 7 = 13

So 13 is the value.

Substitution

When we replace letters by numbers, we substitute those numbers into the expression.

Important: Use grouping symbols such as ( ), [ ], or { } to specify the order of operations (calculations).

Use ( ) around each quantity (number) being substituted so the form of the algebraic expression does not change.

The innermost ( ) are calculated first.

If there are no specified grouping symbols, multiplication and division are done first before addition and subtraction.

If we want to add first, we write this as a(b + c).

The multiplication sign × is often omitted.

2 + 4 · 5 = 2 + 20 = 22

Here, multiplication is done before addition.
