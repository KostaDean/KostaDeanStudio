Simplifying Expressions

The form of a quantity can be changed while keeping the value of the quantity the same.

Basic rules for transformation

These rules change the form of a quantity while keeping its value the same.

1) Distributive rule:

a(b + c) = ab + ac

2) Commutative rule:

ab = ba
a + b = b + a

3) Associative rule:

a(bc) = (ab)c
a + (b + c) = (a + b) + c

Simplifying expressions

We use these rules to simplify expressions.

2x + 3x + 4y − 3y
= (2x + 3x) + (4y − 3y)
= 5x + y
3x(2 − y) = 6x − 3xy
5a − 10b = 5(a − 2b)

Factoring

Using the distributive law in reverse is called factoring.

ab + ac = a(b + c)

With distributing, we express a product as a sum.

With factoring, we express a sum as a product.
