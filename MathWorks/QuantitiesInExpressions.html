QUANTITIES IN AN EXPRESSION

A quantity is a numerical value.

An expression using numbers, variables, operation signs (+, −, ×, ÷), and grouping symbols such as ( ), [ ], and { } is a quantity that has form and can be calculated.

An expression contains other quantities. Learning to see the quantities in an expression is very important.

Example

What are the quantities in the expression

((a+1)[4+2(b+c)])
—————————————
3(b+5d)

The following are quantities inside the expression:

  • (a + 1)
  • 4 + 2(b + c)
  • (b + c)
  • (b + 5d)
  • 3(b + 5d)

Quantities NOT in this expression

These may look like quantities, but they are not quantities in this expression because they do not appear as complete parts of the expression as written:

  • 4 + 2b is not a quantity in this expression.
  • (a + 1) / 3b is not a quantity in this expression.
  • 2(b + c) / 3(b + 5d) is not a quantity in this expression.

Important: A quantity must be a complete part of the expression as it is written, not just pieces taken from different places.

Important idea

A quantity is something that can be treated as one value inside a larger expression.

Expressions are built from smaller quantities.
