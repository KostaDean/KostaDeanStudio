Rates

Rates compare how one quantity changes relative to another quantity.

Definition



Definition:
A rate compares how one quantity changes relative to another quantity.
rate = amount of A / amount of B
per    for every    each    to

Examples

Speed is a rate.

speed = distance / time
200 miles / 4 hours = 50 miles/hour

Slope is a rate.

slope = rise / run

Important Idea



Important Idea:
Amount = Rate × Amount
distance = speed × time
money earned = pay rate × time
toys made = production rate × time

Rules

If   rate = A / B
and   B is known,
then   A = rate × B.
If   distance = d
and   time = t,
then   speed = d / t.

Worked Examples

If speed = 50 miles/hour
and time = 8 hours,
then distance = 50 × 8 = 400 miles.
If rate = 25 toys/hour
and time = 8 hours,
then toys = 25 × 8 = 200 toys.

Parent Note



Parent Note: Focus first on what is being compared. Use easy numbers first. Use a calculator for harder numbers.
