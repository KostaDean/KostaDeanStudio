Graphs of Equations

A solution to an equation with variables x and y gives matching values for x and y that make the equation true.

Solutions as points

Such values can be expressed as (x, y), as coordinates of points on the coordinate plane.

All solution points (x, y) that fit the equation are said to be the graph of that equation.

Rule: The graph of an equation includes all the solutions to the equation.

Example: y = 2x + 1

Choose some values of x. Then calculate the corresponding values of y.

xy = 2x + 1point
01(0, 1)
13(1, 3)
25(2, 5)

The graph of this equation is a straight line.

Checking a point

To check if a point (x, y) is a solution, substitute x and y into the equation.

Example: Is (1, 3) a solution of y = 2x + 1?

Substitute x = 1 and y = 3:

3 = 2(1) + 1 = 3 ✓

Yes, (1, 3) is a solution and is on the graph.
