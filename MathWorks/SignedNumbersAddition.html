Signed Numbers Addition

Recall that (+4) can be expressed as an arrow 4 units to the right, while (−3) can be expressed as an arrow 3 units to the left.

Signed numbers as vectors

The sign gives the direction. The number gives the magnitude.

Adding two signed numbers

Rule: To add two signed numbers, place them end to start on the number line. The signed number you obtain is their sum.

Example: (+5) + (−3)

The blue vector starts at the end of the red vector.
(+5) + (−3) = (+2)

Example: (−5) + (+3)

Again, the second vector begins at the end of the first.
(−5) + (+3) = (−2)

Opposites and subtraction

Rule: The opposite of a number is the number with the opposite sign. We use − to indicate “opposite.”

−(+5) = (−5),   −(−2) = (+2)

Rule: To subtract a signed number, add its opposite.

(+4) − (+3) = (+4) + (−3) = (+1)
(−5) − (−4) = (−5) + (+4) = (−1)
(−7) − (+3) = (−7) + (−3) = (−10)
