Close Enough Calculations

Use nearby easy numbers to estimate answers quickly and check if an answer makes sense.

Why estimate?

Doing arithmetic calculations on paper can be hard sometimes. Close enough calculations can make the work easier and faster.

A close enough calculation is not meant to give the exact answer. It is meant to give an answer that is near the exact answer.

Use easy numbers

We use special numbers like 10, 100, and 1000 to simplify the actual numbers.

These special numbers should be close enough to the actual numbers, but simple enough to handle easily.

Examples

Example 1: Use a close enough easy number to get an upper estimate.

413 + 178 < 413 + 200 = 613

Example 2: Use a close enough easy number to get a lower estimate.

413 + 178 > 400 + 178 = 578

So the actual answer is between 578 and 613.

A very quick close estimate is:

413 + 178 ≈ 400 + 200 = 600

The rule



Rule: To make a close enough calculation, replace hard numbers with close enough easy numbers. Then calculate with those easy numbers. The answer may not be exact, but it should be close.
