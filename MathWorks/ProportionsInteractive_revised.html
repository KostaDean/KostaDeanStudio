Proportions

Equal ratios form a proportion.

Review

A ratio can be written as a fraction.

2 : 1 = 2 / 1
4 : 2 = 4 / 2

If two ratios have the same value, then the ratios are equal.

2 / 1 = 2
4 / 2 = 2

So, 2 / 1 = 4 / 2

Definition



Definition:
Two equal ratios
a / b = c / d
are called a proportion.

Examples

Example:

2 / 1 = 4 / 2

proportion

Example:

3 / 2 = 6 / 4

proportion

Not a proportion:

3 / 4 ≠ 5 / 8

Easy missing-number examples

If the numbers are easy, then we can often find the missing number by inspection.

If   x / 2 = 3 / 1,
then   x / 2 = 3,
then   x = 6.

So:

6 / 2 = 3 / 1

Rules



Rule 1:
If   a / b = c / b,
then   a = c.


Rule 2:
If   a / b = a / d,
then   b = d.


Parent Note: No cross multiplication here. First learn the idea: proportion = equal ratios.

Word problems

If 2 apples cost $4,
then 4 apples cost $8.

2 / 4 = 4 / 8

If 1 toy car has 4 wheels,
then 3 toy cars have 12 wheels.

1 / 4 = 3 / 12
