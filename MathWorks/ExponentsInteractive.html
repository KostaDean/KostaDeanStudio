Exponents

Repeated multiplication

For repeated multiplication by the same quantity x, we use exponents.

x · x = x²
x · x · x = x³
x · x · x · ... · x = xⁿ

The small raised number is called the exponent. It tells how many times the base is used as a factor.

Rules for exponents

xⁿ · xᵐ = xⁿ⁺ᵐ

When multiplying powers with the same base, add the exponents.

xⁿ / xᵐ = xⁿ⁻ᵐ

When dividing powers with the same base, subtract the exponents.

x⁰ = 1

Any nonzero number to the zero power is 1.

(xⁿ)ᵐ = xⁿᵐ

When raising a power to a power, multiply the exponents.

Useful powers

2² = 4    2³ = 8    2⁴ = 16    2⁵ = 32    2⁶ = 64

3² = 9    3³ = 27    3⁴ = 81

5² = 25    5³ = 125

10⁰ = 1    10¹ = 10    10² = 100    10³ = 1000

Example: expanding a square

(x + y)² = (x+y)(x+y)
= (x+y)x + (x+y)y
= x² + xy + xy + y²
= x² + 2xy + y²

This shows why (x+y)² is not just x²+y².
