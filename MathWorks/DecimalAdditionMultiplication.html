Decimal Addition and Multiplication

For decimal addition, add the same equal amounts together: ones with ones, tenths with tenths, hundredths with hundredths.

Addition

Basic rule: Line up the decimal points. Then add column by column.

Place values: (100) hundreds, (10) tens, (1) ones, (0.1) tenths, (0.01) hundredths

Multiplication

Basic rule: Clear all decimal points by multiplying or dividing each number by the proper special number, such as 10, 100, or 1000. Then multiply or divide the answer by those same special numbers.

(12.5) × (0.01) = 12510 × 1100 = 1251000 = 0.125
