Notes to Parents



Notes to Parents:
Filling in missing numbers in a sequence of numbers is the equivalent of practicing scales learning to play the piano. It gets the mind recognizing the pattern and playing the notes. A very effective way to develop numeracy. But only if made easy. So start with some easy to recognize sequences and progressively make these slightly more challenging. Go up the scale by same number, by 2 or 3 for example. And start at different places in the sequence scale, like 0 or 3 etc. Going back is a little mire challenging but shows more mathematical reasoning.
