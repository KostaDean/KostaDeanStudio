Algebraic Equations

Two quantities with equal value but different form make an algebraic equation.

What is an equation?

An equation says that two forms have the same value.

2x − 45 = 3x + 1

This is an algebraic equation in the unknown x.

By isolating x, using rules that keep the equation balanced, we find the value of the unknown.

Rules for solving equations

1) You can add or subtract the same quantity on both sides of the equation.

If a = b, then a + c = b + c

2) You can multiply or divide both sides of the equation by the same non-zero quantity.

If a = b, then 5a = 5b

Using just these two rules and properties of numbers, we can solve the equation.

Solving the example

Solve: 2x − 45 = 3x + 1
5(2x − 45) = 5(3x + 1)
2x − 4 = 15x + 5
2x − 4 − 2x = 15x + 5 − 2x
−4 = 13x + 5
−4 − 5 = 13x + 5 − 5
−9 = 13x
−913 = x
So x = −9/13.

Notes to Parents



Notes to Parents:
Each side of an equation is a quantity. Its very important to enclose each side in parenthesis when operating on both sides of the equation in solving the equation. This is a source of many common mistakes students make.
