Graphs

We can express the relationship between two variable quantities, often written as x and y, by drawing the graph of x and y on the coordinate plane.

Independent and dependent variables

Typically, we call x the independent variable and y the dependent variable.

The point (x, y) is on the graph of x vs. y if the values of x and y are dependent according to the relationship being shown.

Using the graph, we can find the value of y for a given value of x by moving from x to the graph and then horizontally to the y-axis.

Reading a graph

Start at a given x, move to the graph, then move horizontally to the y-axis to read the corresponding value of y.

Examples of graph statements

For the graph above, we can read statements such as:

If x ≥ −2, then y ≥ 0.

If x ≥ 0, then y ≥ 1.

If x ≤ −2, then y ≤ 0.

Notes to Parents



Notes to Parents:
The graph of an equation in x and y provides a visual depiction of the relationship between x and y. It can be a very powerful means to seeing underlying truths of this relationship. If a "picture is worth a thousand words" a "graph is worth a thousand calculations"!

While the equation shows how to accurately calculate the value of y for a given value of x, the graph directly shows what that value is approximately.
