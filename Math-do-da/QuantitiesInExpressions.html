QUANTITIES IN AN EXPRESSION

A quantity has numerical value. It is objective.

A quality has a subjective value. It is a feeling.

An expression using numbers, variables, operation signs (+, −, ×, ÷), and grouping symbols such as ( ), [ ], and { } is a quantity that has form and numerical value and can be calculated. The form describes how the quantity is to be calculated. While the value is the number so calculated.

An expression contains other component quantities. Learning to see the component quantities in an expression is very important.

Example

What are the component quantities in the expression

((a+1)[4+2(b+c)])
——————— 
3(b+5d)

The following are component quantities inside the expression:

  • (a + 1)
  • 4 + 2(b + c)
  • (b + c)
  • (b + 5d)
  • 3(b + 5d)

Quantities NOT in this expression

These may look like quantities, but they are not component quantities in this expression. They are not used in calculating the value of the expretion.:

  • 4 + 2b is not a component quantity in this expression.
  • (a + 1) / 3b is not a component quantity in this expression.
  • 2(b + c) / 3(b + 5d) is not a component quantity in this expression.

Important: A quantity must be a component part of the expression. It must first be calculated before the whole expression can be calculated.

Important idea

A component quantity is something whose value is used to calculate the larger expression.

Expressions are built from smaller component quantities.

Notes to Parents:
Algebraic expressions can often be intimidating for young learners. Helping them to see expressions by seeing the component quantities that make them up is very important to correctly work with algebraic expressions. Mastering such skill is half of the skill needed doing Algebra.
